# Playmobil Manager - Roadmap

## Objetivo

Crear una aplicación de escritorio para gestionar una colección de Playmobil utilizando Java, JavaFX y MySQL.

El objetivo del proyecto es desarrollar una aplicación funcional y estructurada aplicando buenas prácticas de programación, separación de responsabilidades, persistencia de datos, validación, testing y documentación.
