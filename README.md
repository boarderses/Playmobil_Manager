# Playmobil_Manager

Aplicación de escritorio desarrollada en Java y JavaFX para gestionar una colección de Playmobil mediante una base de datos MySQL.
El proyecto ha sido desarrollado siguiendo una arquitectura por capas (Modelo, DAO y Controlador), aplicando buenas prácticas de programación, validación de datos y una interfaz gráfica moderna.

# Características
- Gestión completa de Playmobil (CRUD)
- Búsqueda en tiempo real por referencia y nombre
- Gestión de categorías mediante ComboBox
- Validación de datos de entrada
- Control de referencias duplicadas
- Gestión de imágenes mediante FileChooser
- Visualización de imágenes en miniatura
- Visor de imágenes a tamaño completo mediante doble clic
- Dashboard con estadísticas de la colección
- Gráfico de distribución por categorías
- Interfaz moderna con JavaFX y CSS
- Persistencia de datos en MySQL

# Tecnologías utilizadas
- Java 21
- JavaFX
- MySQL
- JDBC

- Git y GitHub

- CSS

# Arquitectura

El proyecto está organizado siguiendo una arquitectura por capas:

- **Model** → Entidades del dominio.
- **DAO** → Acceso a base de datos.
- **Controller** → Lógica de la interfaz.
- **Util** → Utilidades y clases auxiliares.
- **Validation** → Validación de datos.
- **Resources** → Archivos FXML, CSS e imágenes.
