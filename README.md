# Playmobil_Manager
Aplicación de escritorio desarrollada en Java y JavaFX para gestionar una colección de Playmobil.

# Funcionalidades previstas
- Alta de productos
- Edición de productos
- Eliminación de productos
- Búsqueda por referencia y nombre
- Gestión de imágenes
- Almacenamiento en MySQL

# Tecnologías
- Java 21
- JavaFX
- MySQL
- JDBC
- Maven
- Git/GitHub
